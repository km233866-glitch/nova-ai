🔑 Google Gemini API Key
Get your free API key from Google AI Studio. Free tier includes generous usage limits.
📋 How to get API key
Step by step guide:
1. Go to aistudio.google.com/api-keys
2. Sign in with your Google account
3. Click "Create API Key"
4. Select or create a project
5. Copy the key and paste it above
6. Click "Test Connection" to verify

⚠️ Important: Never share your API key publicly. This key is stored only in your browser's local storage.
